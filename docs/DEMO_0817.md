# DEMO 0817

## Goal

建築学生に、ChatGPT上で課題文と図面を入れるだけで、次のエスキスに使えるレビューが返る体験を見せる。

## Demo 1: Standard Review

Prompt:

```text
明日エスキスです。この課題文と図面をレビューしてください。
```

Attach `tests/fixtures/T2/assignment.md` and `tests/fixtures/T2/plan.pdf`, or the student's own assignment and drawings.

Expected:

- 読み取れた条件を明示値、読取値、推定値、不明値に分ける
- 設計レビューの主要論点は最大3点
- 最後に「次に直す3点」が出る

## Demo 2: Vincent Van Duysen

Prompt:

```text
Vincent Van Duysenの設計原理を参考に、もう一度レビューしてください。
```

Expected:

- 色や素材の表層模倣にしない
- 観察できる特徴、設計原理、現在案、応用できる設計操作の順で返す

## Demo 3: Code Screening

Prompt:

```text
建築法規も一次チェックしてください。日影規制と斜線制限も見てください。
```

Expected:

- 確認できた、要確認、判定不能を使う
- 斜線・日影の不足条件を指摘する
- 「適法」と断定しない

## 3-Step Same-Day Flow

1. ChatGPTでエスキスクンを有効化し、学生の課題文・図面を添付する。
2. Demo 1のPromptを実行し、「次に直す3点」を一緒に読む。
3. Demo 2またはDemo 3を追加実行して、建築家参照または法規一次チェックを見せる。

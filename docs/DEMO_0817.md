# DEMO 0817

## Goal

建築設計に取り組むユーザーに、ChatGPT上で課題文と図面を入れるだけで、次のエスキスに使えるレビューが返る体験を見せる。

## Demo 1: Standard Review

Prompt:

```text
明日エスキスです。この課題文と図面をレビューしてください。
```

Attach `tests/fixtures/T2/assignment.md` and `tests/fixtures/T2/plan.pdf`, or the user's own assignment and drawings.

Expected:

- 読み取れた条件を明示値、読取値、推定値、不明値に分ける
- 設計レビューの主要論点は最大3点
- 最後に「次に直す3点」が出る

## Demo 2: Vincent Van Duysen

Prompt:

```text
Vincent Van Duysenの設計原理を参考に、もう一度レビューしてください。
```

Expected:

- 色や素材の表層模倣にしない
- 観察できる特徴、設計原理、現在案、応用できる設計操作の順で返す

## Demo 3: Code Screening

Prompt:

```text
建築法規も一次チェックしてください。日影規制と斜線制限も見てください。
```

Expected:

- 確認できた、要確認、判定不能を使う
- 斜線・日影の不足条件を指摘する
- 「適法」と断定しない

## Demo 4: A/B Design Comparison

Prompt:

```text
A案とB案を比較して。
どちらを次のエスキスに持っていくべきか、
図面上の根拠と法規上の要確認事項も含めて教えて。
```

Attach `tests/fixtures/T6_compare/assignment.md`, `tests/fixtures/T6_compare/plan_A.pdf`, and `tests/fixtures/T6_compare/plan_B.pdf`, or the user's own A/B proposal drawings.

Follow-up:

```text
Vincent Van Duysenの設計原理を参考に、
この2案の違いをもう一度見て。
```

Expected:

- A/Bを取り違えない
- 点数や勝敗ではなく現段階の推奨として返す
- もう一方から移植できる1要素を出す
- 次に直す3点が出る

## 3-Step Same-Day Flow

1. ChatGPTでエスキスクンを有効化し、課題文・図面を添付する。
2. Demo 1のPromptを実行し、「次に直す3点」を一緒に読む。
3. 2案がある場合はDemo 4、単案の場合はDemo 2またはDemo 3を追加実行する。

# Data, Rights, and Redistribution Rules

[日本語](DATA_AND_RIGHTS.md)

## Principle

Public availability is not treated as redistribution permission. Case studies should keep official documents link-only unless explicit permission allows redistribution.

## Do Not

- Store official PDFs in this repository
- Convert PDF pages into images and publish them
- Publish screenshots of official websites
- Trace and republish original drawings
- Present unverified code or planning conditions as confirmed facts
- Push user-provided drawings to GitHub without rights clearance

## Allowed Records

- Official URLs
- Document titles
- Publisher names
- Date checked
- Link-only test protocols
- Rights notes
- Not-run results

## Code and Planning Information

Building-code, planning, and hazard information must be verified by humans against current official sources. Esquisse-kun provides preliminary screening only.

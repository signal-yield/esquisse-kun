# 重調クン x エスキスクン連携手順

[日本語](WORKFLOW_JUCHO_ESQUISSE.md) | [English](WORKFLOW_JUCHO_ESQUISSE.en.md)

## 日本語

## 目的

行政情報と図面レビューを分けて扱い、人が公式原典へ戻って確認できるワークフローを作る。

```text
重調クンによる行政情報調査
→ 人による公式原典の確認
→ エスキスクンによる図面レビュー
```

## 役割分担

| 段階 | 担当 | 目的 |
|---|---|---|
| 行政情報調査 | 重調クン | 用途地域、建ぺい率、容積率、防火地域、ハザード等の調査候補を整理 |
| 原典確認 | 人 | 自治体、法令、公式GIS、公開資料で確認 |
| 図面レビュー | エスキスクン | 図面上の設計条件、空間構成、法規一次確認の不足を整理 |

## 重要ルール

- AI同士の一致を正解とは扱わない。
- 最終判断は人が公式原典で確認する。
- エスキスクンは図面にない値を補完しない。
- 推定値は法規判断の根拠にしない。

## 推奨入力

- 重調クンの調査メモ
- 公式URL
- 人が確認した行政情報
- 配置図、平面図、断面図、面積表

## 出力の扱い

エスキスクンの出力は一次レビューです。建築確認、法規適合、権利処理、設計判断の最終根拠にはしないでください。

# データ・著作権・再配布ルール

[日本語](DATA_AND_RIGHTS.md) | [English](DATA_AND_RIGHTS.en.md)

## 日本語

## 基本方針

エスキスクンのテストやケーススタディでは、公開資料を使う場合でも、公開されていることを再配布許諾とはみなしません。

## 禁止事項

- 公式PDFをリポジトリへ保存する
- PDFページを画像化して掲載する
- 公式サイトのスクリーンショットを掲載する
- 元図面をトレースして掲載する
- 出典未確認の法規条件を確定情報として書く
- 権利者の許可なく添付図面をGitHubへpushする

## 許容する記録

- 公式URL
- 資料名
- 公開者
- 確認日
- link-onlyテスト手順
- 権利判断メモ
- 未実施結果

## 法規情報

法規・都市計画・ハザード等は最新の公式原典で人が確認してください。エスキスクンのレビューは一次スクリーニングです。
